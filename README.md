# Lost&Found Docs

Application mobile de restitution de documents officiels (Douala), développée en **.NET MAUI** (C#, XAML, MVVM).

> **État : frontend uniquement.** Aucun backend, aucune API, aucune base de données. Les données sont fictives et gardées en mémoire ; les simulations sont signalées dans le code (`// SIMULATION`) et dans l'interface.

Le README complet (lancement, simulations, compte de démonstration) est complété à la fin de la phase A.
